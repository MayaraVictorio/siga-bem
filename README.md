# Siga Bem – Gestão de pneus para frota de caminhões

**Siga Bem** é um aplicativo web desenvolvido para a disciplina de Laboratório de Criatividade e projetos para a Universidade Luterana do Brasi, usando as seguintes tecnologias React + TypeScript + Vite, criado para auxiliar no controle e acompanhamento de inspeções de frotas de caminhões.  
O sistema permite gerenciar informações de pneus, histórico de inspeções, QR Codes de identificação e dashboards de status.

---

## Funcionalidades

- **Tela de Login:** autenticação simples para acesso ao sistema.  
- **Dashboard:** resumo visual das inspeções realizadas, status de condição e estatísticas gerais.  
- **Leitura de QR Code:** identificação rápida dos veículos ou pneus cadastrados.  
- **Histórico:** acesso ao histórico completo de inspeções.  
- **Inspeção:** formulário intuitivo para registrar condições de cada item monitorado.
